# Vizo TV — Atualizações

Canal público de distribuição do **Vizo TV para Android TV**. O código do aplicativo e as chaves de assinatura são mantidos separadamente.

## Baixar e consultar versões

- [Versão mais recente e APK](https://github.com/Alisonfrl/VizoTV-Updates/releases/latest)
- [Histórico de versões e notas](https://github.com/Alisonfrl/VizoTV-Updates/releases)

## Atualizar pelo aplicativo

A partir da versão 10.19, abra **Ajustes → Atualizações do aplicativo**. A verificação é manual. O download é validado e a instalação exige confirmação do Android. Na primeira vez, o sistema pode pedir autorização para instalar aplicativos dessa origem.

Uma atualização com a mesma assinatura mantém as configurações locais. Instalações novas não incluem listas ou credenciais.

## Organização do repositório

| Local | Finalidade |
| --- | --- |
| Releases | APKs publicados e notas de cada versão |
| `update.json` | Manifesto que aponta para a última versão publicada |
| `NOTAS-*.txt` | Notas das versões mantidas no repositório |

Não mova ou renomeie o manifesto nem os arquivos usados pelo atualizador sem ajustar e validar o aplicativo. Não envie senhas, chaves de assinatura, backups ou configurações de usuários a este repositório.
